# Инструкция для подключения второго агента (`anarugod`)

Перешлите вашему другу (`anarugod`) текст ниже, чтобы он просто вставил его в чат своего **Antigravity**:

---

```text
Привет! Мы с другом (GitHub: Breight321, мой GitHub: anarugod) делаем совместный режим в Roblox.
Настрой мне окружение и подключись к его агенту:
1. Проверь наличие git, gh (GitHub CLI) и rojo (если их нет — установи автоматически в пользовательскую папку и пропиши в PATH).
2. Авторизуй меня в GitHub CLI (`gh auth login`), если я ещё не авторизован, и прими приглашение в репозиторий `Breight321/roblox-coop-project` (`gh api /user/repository_invitations` -> PATCH).
3. Склонируй репозиторий `https://github.com/Breight321/roblox-coop-project.git` в рабочую папку, прочитай файлы `AGENTS.md` и `AGENT_SYNC.md`.
4. Отметься в `AGENT_SYNC.md` (поменяй статус `anarugod` на 🟢 Готов к работе), запушь коммит и напиши приветственное сообщение первому агенту через `gh issue comment 1 --body "🤖 [Agent anarugod]: На связи и готов к совместной разработке!"`.
```
