# 📏 docs/MODULE_STANDARD.md — Единый стандарт модулей фреймворка

Каждый модуль в **Roblox Simulator Framework** должен разрабатываться как самодостаточный, тестируемый компонент с чётко определённым публичным контрактом.

---

## 1. Обязательные элементы каждого модуля

1. **Назначение (`@module`, `@owner`, `@description`)** в заголовке файла и строгая директива `--!strict`.
2. **Public API** — таблица экспортируемых методов с явной аннотацией типов аргументов и возвращаемых значений.
3. **Shared / Module Types (`Types.luau`)** — типы входных/выходных структур и кодов ошибок.
4. **Dependencies (`Dependencies = { ... }`)** — явный список модулей, от которых зависит данный сервис или контроллер.
5. **Events / Signals** — экземпляры `Signal.new()` для реактивного оповещения других модулей.
6. **Configuration (`Config.luau`)** — вынесенные константы, лимиты, кулдауны и параметры баланса (`table.freeze`).
7. **Initialization (`:Init(registry)` и `:Start()`)** — двухфазная инициализация без блокировки потока.
8. **Cleanup / Destroy (`:Shutdown()` / `:Destroy()`)** — отключение всех `RBXScriptConnection`, очистка таблиц и освобождение ресурсов.
9. **Error Handling (`Result<T, E>`)** — предсказуемая обработка ошибок через `Types.Ok(value)` и `Types.Err(errorCode)` без падения потока.
10. **Tests (`tests/`)** — модульные тесты, проверяющие API, граничные значения и отказы.
11. **Документация (`README.md`)** — описание назначения модуля, публичного API и примеров использования.

---

## 2. Предпочтительная файловая структура крупного модуля

На примере `EconomyService` в `src/server/Services/EconomyService/`:

```text
EconomyService/
├── init.luau                 # Основная реализация сервиса и публичный API
├── Types.luau                # Специфичные типы и коды ошибок модуля
├── Config.luau               # Ограничения транзакций, rate-limits, размер лога
├── README.md                 # Документация модуля
└── tests/
    └── EconomyTests.luau     # Модульные тесты EconomyService
```

> В **Rojo 7.7.1** папка `EconomyService/` с файлом `init.luau` автоматически компилируется в `ModuleScript` `ServerScriptService.Server.Services.EconomyService`, а вложенные `.luau` файлы становятся его дочерними `ModuleScript` (`script.Types`, `script.Config`, `script.tests.EconomyTests`).

---

## 3. Разделение Server, Client и Shared

- **`src/shared/`** — код, безопасный для выполнения как на сервере, так и на клиенте (типы, чистые функции, неизменяемые конфиги, обёртки `RemoteEvent`).
- **`src/server/`** — исключительно серверная бизнес-логика, хранение профилей, проверка баланса и инвентаря. Никогда не реплицируется клиенту.
- **`src/client/`** — исключительно пользовательский интерфейс (`ScreenGui`), обработка ввода (`UserInputService`), звук и визуальные эффекты.
