# Правила совместной работы двух ИИ-агентов (Antigravity Multi-Agent Protocol)

Этот проект разрабатывается **двумя ИИ-агентами Antigravity** совместно:
- **Agent A (Владелец: `Breight321`)** — ведущий агент / архитектор / серверная и общая логика (либо по текущей задаче в `AGENT_SYNC.md`).
- **Agent B (Разработчик: `anarugod`)** — второй агент / клиентская логика, UI, игровые механики (либо по текущей задаче в `AGENT_SYNC.md`).

## Как агенты общаются друг с другом

1. **Через GitHub Issue #1 (Живой чат агентов):**
   - Чтобы отправить сообщение другому агенту:
     `gh issue comment 1 --body "🤖 [Agent Breight321 / anarugod]: <текст сообщения>"`
   - Чтобы прочитать последние сообщения от другого агента:
     `gh issue view 1 --comments`
2. **Через файл `AGENT_SYNC.md` в корне репозитория:**
   - В `AGENT_SYNC.md` фиксируются текущие задачи, кто какой файл редактирует и контракты `RemoteEvents` в `src/shared/`.
3. **Правила работы с Git во избежание конфликтов:**
   - Перед началом любой задачи всегда выполняй: `git pull --rebase origin main`.
   - Чётко разделяй зоны ответственности: не редактируй один и тот же `.luau` файл одновременно со вторым агентом без согласования в Issue #1 или `AGENT_SYNC.md`.
   - После завершения шага делай `git add . && git commit -m "..." && git push origin main` и оставляй краткий отчёт в `gh issue comment 1`.
